# Working Agreement

- Source of truth: `.codex-product/`
- Version format: `vX.Y.Z`
- Branch format: `codex/<version>-<theme>`
- Artifact order: brief -> requirements -> PRD -> low-fi -> high-fi -> UX spec -> architecture -> data -> frontend -> backend -> test -> release -> retro
- Definition of ready: PRD, UX spec, architecture, and data model reflect the current version scope
- Definition of done: implementation merged, tests run, release notes updated, retrospective captured
