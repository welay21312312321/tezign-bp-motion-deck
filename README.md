## 交互与响应式

桌面默认逐页演示；窄屏默认连续阅读。支持目录、键盘上一页 / 下一页、Home / End、触摸切换、hash `#p1` 至 `#p18`、全屏、阅读模式、动效开关。按减少动态效果的系统偏好默认关闭动效。完整手机作品按用户播放加载，离开可见区域时暂停。

用于验收的接口：

```js
ClientDeck.getState();
ClientDeck.navigate(13);       // 第 14 页，索引从 0 开始
ClientDeck.setMode('reading');
ClientDeck.setMode(false);     // 逐页演示
ClientDeck.setMotion(false);
```
